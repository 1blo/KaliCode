# MyGame — Rojo project

A Roblox game built as a [Rojo](https://rojo.space) project: Luau source in git,
place files generated by `rojo build`.

```
default.project.json     maps source folders to the instance tree
src/server/             server Scripts (.server.lua)
src/client/             client LocalScripts (.client.lua)
src/shared/             shared modules (require-able from both)
src/remotes/            RemoteEvents / RemoteFunctions
src/map/                scene instances (.model.json)
```

## Build

```bash
rojo build . --output build.rbxl
```

The binary `.rbxl` is what you publish — Open Cloud currently drops the
default character controls when publishing from an `.rbxlx` file.

## Publish

With Kali Code, just ask it. It will commit, build, and call the Open Cloud
Place Publishing API:

```
publish the game
```

Or manually:

```bash
rojo build . --output build.rbxl
curl --location --request POST \
  'https://apis.roblox.com/universes/v1/<UNIVERSE_ID>/places/<PLACE_ID>/versions?versionType=Published' \
  --header 'x-api-key: <API_KEY>' \
  --header 'Content-Type: application/octet-stream' \
  --data-binary @build.rbxl
```

The API key needs the `universe-places:write` scope and access to this
experience (Creator Dashboard → API Keys → Access Permissions).
